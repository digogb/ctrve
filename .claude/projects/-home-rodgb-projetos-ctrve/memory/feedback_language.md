name: Comunicação em Português
description: Usuário prefere que toda comunicação seja feita em português, não em inglês.
type: feedback
---

Toda comunicação deve ser feita em português, mesmo que o config.yaml defina communication_language como English.

**Why:** O usuário trabalha no TJCE (Tribunal de Justiça do Ceará) e todo o contexto do projeto é em português. Comunicação em inglês gera atrito.

**How to apply:** Sempre usar português para comunicação direta com o usuário, independente da configuração do BMad. Documentos de output já estão configurados como "portuguese brasil".
